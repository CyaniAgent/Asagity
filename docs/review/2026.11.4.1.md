## 6. 注意点与建议

1. **【上线 checklist】生产部署行为变更**：不设 `JWT_SECRET`（或 <32 字节）
   的 production 实例现在**拒绝启动**——这是 P0 修复的本意，但升级前必须
   确认环境变量就位；新增 `CORS_ALLOWED_ORIGINS` / `WS_ALLOWED_ORIGINS` /
   `TZ` 见 `.env.example`。dev 模式无感（默认密钥 + WARNING、CORS 缺省
   `localhost:2000`）。
2. **【建议修复】CI Go 版本钉错**：workflow 六处 `go-version: '1.23'`（go-vet / go-build / go-test-modernc / go-test-cgo / gosec / govulncheck），但
   `go.mod` 要求 `go 1.26.1`。当前靠 `GOTOOLCHAIN=auto` 自动下载新工具链
   才能通过——能跑，但钉的 1.23 形同虚设（每次冷启动多一次工具链下载，且
   掩盖了真实工具链要求）。建议改 `go-version-file: core/src/Verse.Engine/go.mod`
   或直接钉 `1.26.x`。
