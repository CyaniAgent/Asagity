# Termity Command List
| Root Command | Name | Description |
| :--- | :--- | :--- |
| `anet` | Asagity NET Config | Asagity NET 监测、管理、配置 |
| `exit` | Exit Termity | 退出此 Termity 会话 |
| `func` | Function Switch | 修改 Asagity 的一些可修改功能（部分功能需要管理员用户） |
| `help` | Help | 帮助，查看所有可用的指令 |
| `info` | Server Information | 查看本 Asagity 实例的相关信息 |
| `remote` | Remote Instance | (类似于SSH，目前不开发) 通过特定的 Bearer Token 连接到其他基于 ActivityPub / Asagity 的实例，并可执行 Termity 原生指令 (Asagity) 与 API Console (所有 ActivityPub 实例) 与 AiScript 代码 (Misskey 及其衍生项目 + Asagity) |

Note: 这里只会列出根指令，根指令附属的子指令帮助请使用`[Root Command] --help`指令查看相关帮助。
